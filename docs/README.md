# Architecture Documentation

This folder contains architecture diagrams and the scripts used to generate them.

## Diagram Levels

- Level 0: Business-friendly flow. Shows what happens from client input to final report.
- Level 1: Agent internals, RAG, data boundaries, and feedback loops.
- Level 2: APIs, UI integration, deployment, Kubernetes, and runtime concerns.
